# 17.1 — 2025 Road Glide: Modern Architecture

**Estimated time:** Reading 26m · Video ~12m · Garage 30m · **Total ~68m**

## Why this lesson matters

The modern Road Glide is not a different species of machine; it is a familiar motorcycle with more tightly integrated control systems. Start by mapping engine, cooling, fuel, electrical, chassis and rider-interface systems. Harley-Davidson lists a 117 cu in Milwaukee-Eight 117, ESPFI, liquid-cooled cylinder heads, six-speed gearing and belt final drive. The learning goal is to connect those modern implementations back to the mechanical fundamentals already covered.

:::info Modern-bike rule
The 2025 Road Glide is used to teach architecture and diagnostic thinking. For torque values, fluid specifications, software procedures, ABS service, calibration and component tests, use the correct Harley-Davidson owner/service information for the exact motorcycle.
:::

## What to understand

1. Mechanical fundamentals still come first: power, ground, fuel, air, compression, hydraulics and physical condition.
2. Sensors and modules add information and control paths; they do not make basic testing obsolete.
3. Low voltage, poor grounds and connector faults can imitate expensive electronic failures.
4. A diagnostic trouble code identifies a detected condition or circuit; it does not prove which component to replace.
5. Safety-related systems deserve factory procedures and conservative work practices.

## Compare the four bikes

- **1995 Sportster 883 Hugger:** mechanically accessible, carbureted baseline.
- **1996 Ultra Classic:** classic touring complexity but still a largely analog/carbureted learning platform.
- **1998 Shadow Aero 1100:** liquid cooling and shaft drive add a different mechanical architecture.
- **2025 Road Glide:** ESPFI, modern electronics, rider aids and TFT interface add control/software layers to the same motorcycle fundamentals.

## Garage lab

On the bike, identify the radiator/cooling path, throttle body/intake path, major electrical access points, ABS hardware you can safely observe, TFT controls, final-drive belt and rear suspension. Do not disconnect modules or open pressurized/hot systems.

## Knowledge check

1. What mechanical checks should happen before blaming a control module?
2. Why is a fault code not the same thing as a failed part?
3. Which work in this lesson should be deferred until the correct factory procedure is available?

<details>
<summary>Suggested answers</summary>

Start with battery condition/system voltage, powers and grounds, connectors and the physical system being controlled. A code reports what the controller detected, so wiring, voltage, sensors, mechanical faults or the module itself can be involved. ABS bleeding, calibration/programming, module tests and specification-dependent work should follow the correct factory procedure.
