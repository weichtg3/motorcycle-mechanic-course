# Diagnostic Workflow

1. **Verify the complaint.** Describe exactly when it occurs.
2. **Check fundamentals.** Fuel, battery/voltage, obvious wiring, fluids, controls, leaks and mechanical damage.
3. **Choose the system.** Fuel/air, ignition/electrical, engine mechanical, drivetrain, brakes/chassis.
4. **Measure before replacing.** Voltage drop, compression, fluid condition, free play, pressure, temperature, wear limit, etc.
5. **Change one thing.** Avoid stacking unverified repairs.
6. **Verify the repair.** Re-test the original symptom and perform all required safety checks before riding.
