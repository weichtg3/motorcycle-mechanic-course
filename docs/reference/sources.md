# Sources & verification notes

This course is original educational material. It uses public manufacturer/model references for orientation and links to third-party videos for demonstrations. It intentionally avoids reproducing service-manual procedures or copyrighted course material.

Useful public references used during course construction include:

- Honda Global, **1998 Shadow Aero launch/specification release**: https://global.honda/en/newsroom/worldnews/1998/2980129.html
- Dennis Kirk factory-spec reference for **1996 Harley-Davidson Electra Glide Ultra Classic FLHTCU**: https://www.denniskirk.com/factory-spec/1996-harley-davidson-electra-glide-ultra-classic-flhtcu
- Docusaurus documentation: https://docusaurus.io/docs
- GitHub Pages documentation: https://docs.github.com/pages

## Factory information policy

Do not copy torque values or capacities from this website unless the lesson explicitly cites a verified factory source. The course teaches *what to measure and why*; your bike-specific factory literature supplies the authoritative number and exact sequence.
