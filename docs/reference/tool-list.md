# Master Tool List

## Buy now
Metric and SAE socket/combination-wrench sets; quality screwdrivers; Torx/hex keys appropriate to the bikes; 3/8-inch torque wrench covering common service values; pliers; picks; tire-pressure gauge; digital multimeter with fused current input; drain pan; funnels; shop towels; nitrile gloves; eye protection; flashlight; magnetic tray; labels/bags; service manuals.

## Buy as needed
Low-range and higher-range torque wrenches, feeler gauges, digital caliper, compression gauge, vacuum gauges/synchronizer, motorcycle lift/jack, wheel/bearing tools, brake bleeding tools, specialty sockets, electrical back-probes and crimp tools.

## Specialty / consider borrowing or professional service
Tire machine/balancer, hydraulic press, bearing puller/installer sets, valve-seat/machine tools, crankshaft/transmission specialty fixtures, powder-coating/plating equipment and precision engine machining tools.

:::warning
Tool fit and range matter. A torque wrench is most useful when the target value is comfortably inside its working range. Never use a torque wrench as a breaker bar.
:::
